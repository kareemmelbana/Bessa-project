# Purrfectly Yours

فى المشروع ده :



عايزه صوره ال hero بتاع القطه تبقى هيا ال background كله لل hero متبقاش صغيره كده 



و عايز زرار سلاله نادره يبقى كده زى الصوره الى رفعتهالك 



و عدّل قسم Cat Breeds بحيث يعرض 12 سلالة فقط في البداية، مع زر "عرض جميع السلالات" لإظهار الـ64 سلالة كاملة. عند الضغط استخدم Smooth/Staggered Animation، وعند الضغط مرة أخرى يتحول الزر إلى "إخفاء السلالات" ويعود للـ12. حافظ على الـUI والـstyling والـSearch والـFilters والـdata الحالية بدون أي تغييرات أخرى 



و أضف Entrance Animation عند فتح الموقع: الـNavbar يظهر بـFade + Slide Up، ثم العنوان والـFilters، وبعدها الـCat Cards تظهر واحدة وراء الأخرى بـStaggered Fade + Slide Up Animation بشكل ناعم واحترافي. استخدم animation خفيفة بدون مبالغة، وحافظ على الـUI والـdata والـSearch والـFilters الحالية كما هي.



و طوّر المشروع ليكون أكثر احترافية مع الحفاظ على الـUI والـdata الحالية:







- حسّن الـHero Section والـSearch.



- طوّر الـFilters وأضف Clear All وعدد النتائج.



- حسّن الـCat Cards والـHover Effects وأضف Favorites ❤️.



- اعرض 12 سلالة افتراضيًا مع Show All لإظهار الـ64.



- أضف Entrance/Staggered Animations عند فتح الموقع وتغيير النتائج.



- أضف Breed Details Page مع معلومات السلالة وSimilar Breeds.



- احفظ الـFavorites في localStorage.



- اهتم جدًا بالـResponsive Design والموبايل والـMicro-interactions.



- اجعل كل شيء Smooth وModern بدون تغيير هوية التصميم أو كسر أي Feature موجود.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
